# Aula 07 — Exercícios de processamento e análise de dados

## Objetivo
Reunir exercícios em C para praticar leitura de valores, repetição, contadores, acumuladores e estruturas condicionais.

## Arquivos
| Arquivo | Descrição geral |
|---|---|
| `exercicio01_positivo_negativo.c` | Leitura e classificação de valores positivos e negativos. |
| `exercicio02_loja_vendas.c` | Processamento de dados relacionados a vendas. |
| `exercicio03_aprovacao_alunos.c` | Análise de notas e situação de aprovação de alunos. |
| `exercicio04_temperatura_municipio.c` | Leitura e análise de temperaturas de um município. |

## Conceitos praticados
- Variáveis e expressões aritméticas.
- Estruturas de repetição e condicionais.
- Contadores e acumuladores.
- Comparação de valores e identificação de resultados.
- Entrada e saída com `scanf` e `printf`.

## Compilação e execução
Exemplo a partir da raiz do repositório:

```bash
gcc "AULA 07/exercicio01_positivo_negativo.c" -o exercicio_aula07
```

Windows: `exercicio_aula07.exe`  
Linux/macOS: `./exercicio_aula07`

Para executar outro exercício, substitua o caminho pelo arquivo desejado. Compile um arquivo por vez.

## Finalidade acadêmica
Desenvolver o raciocínio lógico e transformar enunciados em algoritmos executáveis.
