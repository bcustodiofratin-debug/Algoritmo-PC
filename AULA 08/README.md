# Exercícios Práticos em C: Vetores e Matrizes

Este repositório contém uma coleção de exercícios desenvolvidos na linguagem **C**, focados na manipulação de estruturas de dados homogêneas unidimensionais (**Vetores/Arrays**) e multidimensionais (**Matrizes**). 

Os algoritmos abordam conceitos cruciais como iteração, acúmulo de valores, cálculo de médias estatísticas, busca de valores extremos (máximos) e geração de relatórios simples no terminal.

---

## 📌 Conteúdo do Repositório

| Arquivo | Conceito Principal | Descrição |
| :--- | :--- | :--- |
| `exercicio01.c` | Vetores | Leitura de salários de 8 funcionários e exibição sequencial dos dados inseridos. |
| `exercicio02.c` | Vetores e Média | Leitura de 8 valores, cálculo da média e contagem de quantos valores estão acima da média. |
| `exercicio03.c` | Vetores e Busca | Processamento de salários de 10 funcionários: calcula a média, identifica o maior salário e aponta o índice/posição do funcionário. |
| `exercicio04.c` | Matrizes $3 \times 4$ | Controle de estoque de 3 produtos ao longo de 4 dias. Gera um relatório total por produto e o total geral. |
| `exercicio05.c` | Matrizes $3 \times 1$ | Leitura de notas de estudantes, cálculo de média individual e determinação do aluno com maior desempenho. |

---

## 💻 Recursos e Aprendizados

- **Estruturas de Controle**: Uso de laços `for` simples e aninhados.
- **Manipulação de Arrays**: Armazenamento e leitura indexada em vetores e matrizes.
- **Internacionalização**: Configuração do `setlocale` (`LC_CTYPE`) para suporte a caracteres locais.
- **Lógica Algorítmica**: Acumuladores de soma, contadores condicionais e técnicas para encontrar o maior elemento em um conjunto.

## 🛠️ Como Compilar e Executar

Para executar os exercícios localmente, certifique-se de ter um compilador C instalado (como `gcc`).

### Passo a passo no Terminal (GCC):

1. **Clone o repositório ou baixe os arquivos:**
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git
   cd seu-repositorio
   ```

2. **Compile o arquivo desejado:**
   ```bash
   gcc exercicio01.c -o exercicio01
   ```

3. **Execute o programa:**
   - **Linux / macOS:**
     ```bash
     ./exercicio01
     ```
   - **Windows:**
     ```cmd
     exercicio01.exe
     ```
